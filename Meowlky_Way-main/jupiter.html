MISSÃO 03

JÚPITER

O gigante do Sistema Solar

Zeus chegou ao maior planeta do Sistema Solar. Uma transmissão misteriosa foi encontrada em uma estação espacial, mas existe um problema: o acesso está protegido por uma senha de 5 dígitos.

INICIAR MISSÃO

Você sabia?

🪐

O maior planeta

Júpiter é o maior planeta do Sistema Solar. Seu volume é maior que o de todos os outros planetas juntos.

🌙

Muitas luas

Júpiter possui muitas luas. Entre as mais conhecidas estão Io, Europa, Ganimedes e Calisto.

🌀

Uma tempestade gigante

A Grande Mancha Vermelha é uma enorme tempestade que existe há séculos e é maior que a Terra.

Uma mensagem misteriosa...

Depois de recuperar o dispositivo em Marte, Zeus recebeu um novo sinal vindo de Júpiter. Ao chegar a uma antiga estação de observação, encontrou um painel de segurança bloqueado.

Seu colega deixou uma mensagem escondida no sistema. Para descobrir o conteúdo, Zeus precisará encontrar uma senha de cinco dígitos observando o cenário.

"A resposta está diante dos seus olhos. Observe cada detalhe e não confie na primeira impressão." — Mensagem desconhecida

O código secreto de Júpiter

Encontre os elementos escondidos e descubra a senha para desbloquear a transmissão.

Como descobrir o código?

Observe cuidadosamente o cenário abaixo. Conte a quantidade de cada elemento na ordem apresentada e junte os números para formar uma senha de 5 dígitos.

01 Luas grandes
02 Estrelas amarelas
03 Asteroides
04 Naves espaciais
05 Cristais roxos
